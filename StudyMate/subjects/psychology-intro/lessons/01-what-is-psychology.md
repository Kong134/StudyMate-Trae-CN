## 先看一个场景

你连续三天失眠。朋友说：「你就是想太多了，别想就行。」这句话听起来像心理学，但它既不能验证，也没法反驳——它只是安慰。

心理学要做的，是把这类模糊说法换成**能被数据检验**的说法。这一课解决一个问题：**心理学到底研究什么，凭什么算科学？**

::: goal
读完你能做到三件事：
1. 用自己的话说出心理学的三个关键词；
2. 指出「心理学 = 读心术 / 常识 / 弗洛伊德」这三条误解错在哪；
3. 把一句生活常识改写成可检验的命题。
:::

## 一个定义，三个关键词

::: key 定义
**心理学是研究行为与心理过程的科学。**
- **行为**：可以被外人观察到的动作、言语、选择、生理反应。
- **心理过程**：注意、记忆、情绪、判断等内部活动，不能直接看见，只能通过行为推断。
- **科学**：用可重复的方法收集证据，结论允许被推翻。
:::

注意第二条：心理过程是**推断**出来的，不是"看"出来的。所以心理学永远在解决一个技术问题——**怎么把看不见的东西变成可测量的指标**。这就是后面「操作化定义」要干的事。

## 三条常见误解

::: warn 误解一：心理学就是心理咨询
心理咨询与治疗只是**临床心理学**这一个分支。心理学的很大一部分在研究注意、记忆、决策、学习、群体行为，跟"治病"没关系。
:::

::: warn 误解二：心理学就是常识
常识有两个致命问题：**事后什么都解释得通**，而且**互相矛盾**（"三个臭皮匠"和"三个和尚没水喝"都能成立）。实证结论要求事先给出预测，并且能在数据面前认输。
:::

::: warn 误解三：心理学就是弗洛伊德
精神分析是心理学史的一部分，但现代心理学的主流方法是实验与测量。把弗洛伊德当成心理学的全部，相当于把炼金术当成化学的全部。
:::

## 常识与实证的差别：一个具体例子

假设你观察到：考试前熬夜复习的同学，成绩并不比早睡的同学好。

- **常识式说法**：「熬夜伤身，当然考不好。」——听起来对，但它没有给出任何可测量的预测，也没法说明"为什么"。
- **实证式说法**：「在相同复习时长下，睡眠 5 小时的学生，第二天记忆测试的平均得分低于睡眠 7 小时的学生。」——这里有明确的自变量（睡眠时长）、因变量（记忆得分）、可比较的群体。

第二句才是一个**心理学命题**：它能被数据推翻。如果测出来 5 小时组得分更高，这个说法就错了，而第一句永远不会错——这就是区别。

::: example 例子：把"乐观"变成可研究的问题
「有人天生乐观」这句话里，"乐观"没有定义，也无法计数。改成：

> 在遭遇失败后，高乐观组（用 LOT-R 量表得分前 27%）比低乐观组更快恢复日常作息（以恢复所需天数计）。

此时"乐观"变成一个分数，"恢复"变成一个天数，问题才真正开始。
:::

## 学科地图（先有个轮廓）

| 分支 | 研究什么 | 典型问题 |
| --- | --- | --- |
| 生物心理学 | 大脑与神经机制 | 睡眠不足如何影响注意？ |
| 认知心理学 | 注意、记忆、判断 | 为什么人会记住错误细节？ |
| 发展心理学 | 一生中的变化 | 语言能力何时、如何形成？ |
| 社会心理学 | 群体与他人影响 | 为什么人越多越没人帮忙？ |
| 临床心理学 | 心理障碍与治疗 | 哪种疗法对焦虑更有效？ |

这张表不用背。它只是告诉你：**心理学不是一个话题，而是一组用同一套方法研究不同问题的领域。**

## 练习

::: exercise 练习 1：哪一句是可检验的心理学命题？
判断下面三句，并说明理由。

A. 有的人天生就乐观。  
B. 每天睡足 7 小时的人，第二天记忆测试的平均得分高于只睡 5 小时的人。  
C. 失恋的人应该多出去走走。

::: answer
**答案：B。**

- A 的「乐观」没有操作化（没有量表、没有分数），也没有给出可比较的预测，无法收集数据推翻。
- B 有明确的自变量（睡眠时长）与因变量（记忆测试得分），能设计对比组，测完就能判对错。
- C 是一条**建议**，不是关于世界如何运作的命题；它可以有用，但不属于可检验的科学陈述。
:::
:::

::: exercise 练习 2：改写练习
把「多晒太阳心情会变好」改写成一句可检验的命题，要求写清：比较谁和谁、测量什么、预测方向。

::: answer
参考答案（你的表述不必一样，但三个要素要齐）：

> 连续两周每天户外日照 ≥ 60 分钟的大学生，其抑郁量表（PHQ-9）得分低于每天日照 < 20 分钟的大学生。

要素检查：比较两组人（日照时长不同）→ 测量 PHQ-9 得分 → 预测方向是"日照多的一组得分更低"。
:::
:::
