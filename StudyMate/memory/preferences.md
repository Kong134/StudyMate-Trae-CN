# 讲法偏好与常见卡点

- 心理学：先给生活场景，再给术语，最后给定义——有效。
- 统计：先带具体数字算一遍，再上符号——有效。
- 一次讲超过 3 个新术语会卡住，需要拆成两课。
- 不喜欢大段教材式罗列；要"这课解决什么问题"先说清楚。
- 对"相关性不等于因果"这类判断，需要具体反例才记得住。
- 需要逐行讲清每个配置项为什么这样配、为什么不选别的。
