项目要做什么

写一个命令行程序 wordcount：读入一个文本文件，统计每个单词出现的次数，按频次从高到低输出前 20 名。频次相同按字典序，输出对齐、可读。

约束：只允许 C 标准库，不许 STL、第三方库，也不许调系统命令代替分词。哈希表、链表、排序自己搭，排序可以用 libc 的 qsort。这逼你把前六课串起来。

四步流水线

整个程序是一条单遍流水线：打开文件 → 逐字符切词 → 丢进哈希表计数 → 把 Entry 指针收进数组排序输出。四步能分别测试，不用全写完才跑。

第一步和第二步：读文件、切单词

用 fgetc 逐字符扫描，不按行读——词可能跨行。规则定死：连续字母和撇号算一个词，其余是分隔符，统一转小写。

#include <stdio.h>
#include <ctype.h>

#define WORD_MAX 64

/* 每读到一个词就调用 sink；sink 返回 0 表示中断 */
int each_word(FILE *fp, int (*sink)(const char *, void *), void *ctx) {
    char buf[WORD_MAX];
    size_t len = 0;
    int truncated = 0;
    int c;

    while ((c = fgetc(fp)) != EOF) {
        if (isalpha((unsigned char)c) || c == '\'') {
            if (len + 1 < sizeof buf) buf[len++] = (char)tolower((unsigned char)c);
            else truncated = 1;              /* 超长词直接丢弃，防止写越界 */
        } else if (len > 0) {
            if (!truncated) {
                buf[len] = '\0';
                if (!sink(buf, ctx)) return 0;
            }
            len = 0;
            truncated = 0;
        }
    }
    if (len > 0 && !truncated) {             /* 文件末尾没有分隔符 */
        buf[len] = '\0';
        if (!sink(buf, ctx)) return 0;
    }
    return 1;
}

(unsigned char)c 不能省：isalpha 要求 unsigned char 或 EOF，传负值在部分实现上是未定义行为。UTF-8 中文不会被 isalpha 认成字母，本项目只处理 ASCII 单词。

第三步：哈希表计数

哈希表直接沿用第 6 课的拉链实现：ht_add(ht, word, 1) 找到就加一，找不到就新建 Entry 并复制 key。分词器只负责切词，计数器只负责加一，两者通过 sink 回调连起来，互不依赖。

static int count_word(const char *w, void *ctx) {
    return ht_add((HashTable *)ctx, w, 1);
}

/* 在 main 里这样接起来 */
HashTable ht = {0};
if (!each_word(fp, count_word, &ht)) { ... }

buf 是栈上复用的，下一次读词就被覆盖，所以 ht_add 必须复制 key。直接存 buf 指针的话，所有 key 会变成同一个词——计数看着对，查起来全错。

为什么不用数组存所有词再统计

先存所有词再排序，空间 O(总词数)；哈希表只存不同词，O(词汇量)，查找 O(1)。文本越大差距越明显。

第四步：排序输出

哈希表不保证顺序，先把 Entry 的指针收进数组再排序——Entry 不搬家，只交换指针。规则：频次降序，并列按 strcmp 升序。

static int cmp_count(const void *a, const void *b) {
    const Entry *ea = *(const Entry *const *)a;
    const Entry *eb = *(const Entry *const *)b;
    if (ea->count != eb->count)
        return (eb->count > ea->count) - (eb->count < ea->count);
    return strcmp(ea->key, eb->key);
}

int print_top(const HashTable *ht, size_t topn) {
    if (ht->size == 0) return 1;
    Entry **arr = malloc(ht->size * sizeof *arr);
    if (!arr) return 0;

    size_t k = 0;
    for (size_t i = 0; i < ht->nbuckets; i++)
        for (Entry *e = ht->buckets[i]; e; e = e->next) arr[k++] = e;

    qsort(arr, k, sizeof *arr, cmp_count);
    if (topn > k) topn = k;
    for (size_t i = 0; i < topn; i++)
        printf("%-20s %d\n", arr[i]->key, arr[i]->count);

    free(arr);
    return 1;
}

(eb->count > ea->count) - (eb->count < ea->count) 是三向比较：a 的频次更小时返回正数（a 排到后面），更大时返回负数，相等返回 0，于是频次高的排前面。别写 return ea->count - eb->count，int 相减会溢出。

最后的 main 把四步接起来：参数检查、fopen 检查、计数、输出、free。

int main(int argc, char **argv) {
    if (argc != 2) {
        fprintf(stderr, "usage: %s <file>\n", argv[0]);
        return 1;
    }
    FILE *fp = fopen(argv[1], "r");
    if (!fp) { perror("fopen"); return 1; }

    HashTable ht = {0};
    if (!each_word(fp, count_word, &ht)) {
        fclose(fp);
        ht_free(&ht);
        return 1;
    }
    fclose(fp);

    print_top(&ht, 20);
    ht_free(&ht);
    return 0;
}

里程碑验收

项目拆成四个里程碑，每完成一个就独立验证。别等全写完再跑，否则出错时分不清是哪一步。

里程碑 1：能读文件并切出词

用 test1.txt（内容 Hello, world! It's C.）跑分词，打印每个词。验收点：文件不存在时返回非 0 并打印错误；空文件不崩；词全部小写；It's 按规则切成 it's 一个词。

参考答案

输出应依次是 hello、world、it's、c，共 4 个词。perror("fopen") 能在文件不存在时给出原因；each_word 在 EOF 后还要冲刷缓冲区里的最后一个词，否则 C 会丢。

判断标准：4 个词、没有空串、没有标点残留。

里程碑 2：哈希表能正确累计

test2.txt 内容 apple banana apple。验收点：ht.size == 2；apple 的计数是 2，banana 是 1；ht_get 对不存在的 zzz 返回 0。

参考答案

计数应为 apple=2、banana=1，不同词数 size=2。ht_add 命中已有 key 时只加 count，不增加 size；只有新建 Entry 才 size++。

判断标准：size 与"不同词数"一致，而不是与"总词数"一致。

里程碑 3：大小写和标点归一

test3.txt 内容 Apple, apple! APPLE?。验收点：输出只有一条 apple 3；不会出现 apple, 这种带标点的 key；连续标点、行尾、文件末尾都不产生空词。

参考答案

apple 计数为 3，ht.size == 1。tolower 在拼进 buf 之前调用；分隔符分支里只在 len > 0 时才提交单词，因此连续空格和 !? 都不会产生空串。

判断标准：大小写合并、标点剥离、无空 key 三件事同时成立。

里程碑 4：Top N 排序输出

test4.txt 让 b 和 a 都出现 2 次，c 出现 1 次。验收点：输出顺序为 a 2、b 2、c 1（并列按字典序）；print_top(&ht, 2) 只输出前两条且不越界；空文件不崩。

参考答案

频次降序、并列字典序：a 2、b 2、c 1。topn 大于实际词数时要把它压到 k，否则数组越界；ht->size == 0 时直接返回，避免 malloc(0) 的返回值不确定。

判断标准：排序稳定符合两条规则、Top N 截断正确、空输入有保护。

交付清单与常见坑

提交前对着清单自查：

  • gcc -std=c11 -Wall -Wextra wordcount.c -o wordcount 零警告；-fsanitize=address 跑三份测试文本无泄漏、无越界。
  • 所有 malloc 都有 NULL 检查；fopen 失败走错误分支；fclose 在所有路径上都执行。
  • 释放顺序：先 ht_free（它释放每个 key 和 Entry），再退出；print_top 里的 arr 单独 free。
  • 超长词（超过 63 字符）被丢弃而不是截断成两个词；WORD_MAX 的边界写 len + 1 < sizeof buf，保证给 '\0' 留位。
  • 输出用 %-20s 对齐；词数不足 20 时不打印多余行。

三个必查的崩溃点

  1. fgetc 返回 int，别用 char 接——EOF 是 -1，char 可能是无符号，循环永远不结束。
  2. qsort 的比较函数里 *(Entry *const *)a 的括号不能少，否则你比较的是指针地址。
  3. 空文件和只有标点的文件：ht.size == 0，此时任何"取第一名"的代码都必须先判空。

写完这个项目，动态数组、链表、哈希、排序就串成了一条真实数据通路。
