先说结论

时序逻辑 = 组合逻辑 + 存储。它的输出不只取决于当前输入，还取决于当前状态；而当前状态是过去输入一步步累积的结果。触发器负责"记住"，组合逻辑负责"根据现在和过去算出下一步"。

分析时序电路的核心是三组方程：状态方程（下一状态怎么来）、驱动方程（触发器输入端接了什么）、输出方程（输出怎么来）。把驱动方程代进触发器的特征方程，就得到状态方程；再列状态转换表、画状态图，功能就一目了然了。

本课目标

能从电路图写出驱动方程和状态方程，能列状态转换表、画状态图，能分析一个同步时序电路的功能，并区分 Mealy 与 Moore 输出。

三个方程：状态、驱动、输出

时序电路里的触发器通常共用同一个时钟，这叫同步时序电路；如果各级时钟来自前一级的输出，就是异步时序电路，分析时要额外考虑每级什么时候才翻转。

分析同步电路按固定顺序：

  1. 驱动方程：看每个触发器的输入（D、J、K、T）接了什么信号，写成现态 QQQ 和输入 XXX 的函数。
  2. 状态方程：把驱动方程代进特征方程。D 触发器 Q∗=DQ^*=DQ∗=D，JK 是 Q∗=JQ′+K′QQ^*=JQ'+K'QQ∗=JQ′+K′Q，T 是 Q∗=T⊕QQ^*=T\oplus QQ∗=T⊕Q。
  3. 输出方程：看输出端经过哪些门，写成现态和输入的函数。
  4. 状态转换表：把每个现态和每种输入代入，算出下一状态和输出。
  5. 状态图：一个状态一个框，箭头写"输入/输出"。

这五步做完，还要回答两个问题：它完成什么功能？有没有无效状态？如果有，无效状态能不能自己回到有效循环（自启动）？

现态和次态

QQQ 是"现在"的状态，Q∗Q^*Q∗ 是"下一个时钟沿之后"的状态。写状态方程时用的是现态，别把 Q∗Q^*Q∗ 又代回右边的 QQQ 里，否则会把组合逻辑和记忆混在一起。

状态转换表与状态图

状态转换表把"现态 × 输入"的所有组合列出来，每一行给出下一状态和输出。状态图画法更直观：每个状态一个节点，每条转移一条箭头，箭头标签写"输入/输出"。

以 2 位二进制加法计数器为例，状态 00、01、10、11 依次循环，没有输入，输出就是状态本身。状态图是一个四步的环：00→01→10→11→00。每来一个时钟走一步，走完四步回到起点，所以是模 4 计数器。

检查状态图只需一条规则：每个状态的出边必须覆盖全部输入组合；两个输入变量就要有四条出边（自环也算），漏一条就是错的。

同步时序电路的分析步骤

下面用一个具体电路走一遍。设两个 D 触发器 Q1Q_1Q1​、Q0Q_0Q0​，驱动方程是：

D1=Q0,D0=Q1′Q0′D_1=Q_0,\qquad D_0=Q_1'Q_0'D1​=Q0​,D0​=Q1′​Q0′​

因为 D 触发器的次态等于 D，所以状态方程就是 Q1∗=Q0Q_1^*=Q_0Q1∗​=Q0​，Q0∗=Q1′Q0′Q_0^*=Q_1'Q_0'Q0∗​=Q1′​Q0′​。从 00 出发：下一个状态是 Q1∗=0Q_1^*=0Q1∗​=0、Q0∗=1Q_0^*=1Q0∗​=1，即 01；再下一步 Q1∗=1Q_1^*=1Q1∗​=1、Q0∗=0Q_0^*=0Q0∗​=0，即 10；再下一步 Q1∗=0Q_1^*=0Q1∗​=0、Q0∗=0Q_0^*=0Q0∗​=0，回到 00。序列是 00→01→10→00，三个状态一循环，所以是模 3 计数器。

再看无效状态 11：Q1∗=1Q_1^*=1Q1∗​=1、Q0∗=0Q_0^*=0Q0∗​=0，一步就进入 10，随后并入主循环。所以这个电路是自启动的。如果无效状态算出来仍停在无效状态，或自己形成小环，上电后可能永远出不来，必须改逻辑或加复位。

异步电路不能只看稳态

异步计数器的后级时钟来自前级输出，前级翻转后要等延迟才触发后级。分析时要按"谁先动、谁后动"排时间顺序，不能像同步电路那样假设所有触发器同时更新。毛刺和竞争在异步电路里是常态，不是例外。

实例：101 序列检测器

需求：输入串行数据 X，每检测到连续三位 101 就输出一个脉冲；检测不重叠，检测完回到初始态重新找。

设四个状态：

  • S0：还没收到任何有效位。
  • S1：已收到一个 1。
  • S2：已收到 10。
  • S3：已收到 101，输出 Y=1。

状态转换表如下：

现态 X=0 时次态 X=1 时次态 输出 Y
S0 S0 S1 0
S1 S2 S1 0
S2 S0 S3 0
S3 S0 S0 1

S2 收到 0 为什么回 S0？因为此时串是 100，末尾的 0 不是任何有效前缀（前缀只有 1 和 10），只能从头再来。S1 收到 1 为什么留在 S1？因为 11 的末尾仍是 1，还可以作为新序列的开头。

把状态编码成 S0=00、S1=01、S2=10、S3=11，可以写出 DDD 触发器的驱动方程：

D0=Q1′X+Q1Q0′X=X(Q1′+Q0′)D_0=Q_1'X+Q_1Q_0'X=X(Q_1'+Q_0')D0​=Q1′​X+Q1​Q0′​X=X(Q1′​+Q0′​)

D1=Q1′Q0X′+Q1Q0′XD_1=Q_1'Q_0X'+Q_1Q_0'XD1​=Q1′​Q0​X′+Q1​Q0′​X

输出方程是 Y=Q1Q0Y=Q_1Q_0Y=Q1​Q0​，只有 S3（11）时为 1。D0D_0D0​ 的含义：只要 X=1X=1X=1 且现态不是 S3（Q1Q0≠11Q_1Q_0\ne 11Q1​Q0​=11），下一拍 Q0Q_0Q0​ 就置 1——在 S0、S1 是"收到一个 1"，在 S2（已收到 10）是进入 S3；到 S3 后两项都为 0，下一拍回 S0。

输出与状态编码：Mealy 与 Moore

同样是 101 检测器，输出可以有两种放法：

  • Moore：输出只由现态决定，Y=1 写在状态 S3 里。输出与时钟同步，干净、无毛刺，但比 Mealy 晚一拍。
  • Mealy：输出由现态和输入共同决定，把 Y=1 写在 S2→S3 的箭头上（标签 1/1）。它能更早给出结果，但输入毛刺会直接传到输出。

状态编码也有讲究：二进制编码触发器少；格雷码相邻状态只差一位，毛刺小；独热码每个状态一个触发器，逻辑简单，FPGA 常用。

例子：状态数怎么定

检测长度为 3 的序列，理论上需要 4 个状态（空前缀、长度 1、长度 2、长度 3）。如果允许重叠检测，S3 收到 1 后应回到 S1 而不是 S0；状态数不变，只是转移目标变了。

练习

练习 1：分析模 3 计数器

某同步电路 Q1∗=Q0Q_1^*=Q_0Q1∗​=Q0​、Q0∗=Q1′Q0′Q_0^*=Q_1'Q_0'Q0∗​=Q1′​Q0′​，初始状态 00。写出状态序列、模值和它是否自启动。

参考答案

00→Q1∗=0,Q0∗=1Q_1^*=0,Q_0^*=1Q1∗​=0,Q0∗​=1→01；01→Q1∗=1,Q0∗=0Q_1^*=1,Q_0^*=0Q1∗​=1,Q0∗​=0→10；10→Q1∗=0,Q0∗=0Q_1^*=0,Q_0^*=0Q1∗​=0,Q0∗​=0→00。序列 00→01→10→00，模 3。

无效状态 11→Q1∗=1,Q0∗=0Q_1^*=1,Q_0^*=0Q1∗​=1,Q0∗​=0→10，一步进入主循环，所以是自启动的。

练习 2：S2 收到 0 为什么回 S0

101 检测器中，现态 S2（已收到 10）收到 X=0，为什么下一状态是 S0，而不是 S1？

参考答案

此时输入串的末尾是 100。S1 代表"已收到一个 1"，S2 代表"已收到 10"；100 的末尾是 0，既不是 1 也不是 10，没有任何有效前缀可以复用，所以只能回到 S0 从头开始。

对比：如果现态 S1（已收到 1）收到 0，末尾变成 10，正好是 S2，所以去 S2。

练习 3：Moore 还是 Mealy

把 101 检测器的输出改成"在 S2→S3 的转移上输出 1"，这是哪种输出？它和 Moore 相比各有什么优缺点？

参考答案

输出依赖现态和输入（转移条件 X=1），所以是 Mealy 型。

Mealy 的优点：输出更早（同一拍就给出），状态数可能更少；缺点：输入上的毛刺会直接传到输出，组合路径更长。Moore 的优点：输出只由状态决定，和时钟同步、干净；缺点：晚一拍，状态数可能更多。

练习 4：写驱动方程

101 检测器中 D0=Q1′X+Q1Q0′XD_0=Q_1'X+Q_1Q_0'XD0​=Q1′​X+Q1​Q0′​X，请解释这个式子，并验证现态 S1、X=1 时次态仍是 S1。

参考答案

Q1′=1Q_1'=1Q1′​=1 表示现态在 S0 或 S1，此时若 X=1X=1X=1，D0=1D_0=1D0​=1，下一拍 Q0=1Q_0=1Q0​=1；Q1Q0′=1Q_1Q_0'=1Q1​Q0′​=1 表示现态是 S2（已收到 10），X=1X=1X=1 时也要把 Q0Q_0Q0​ 置 1，才能进入 S3。两项都不满足（现态 S3，或 X=0X=0X=0）时 D0=0D_0=0D0​=0。合并即 D0=X(Q1′+Q0′)D_0=X(Q_1'+Q_0')D0​=X(Q1′​+Q0′​)；Q1Q_1Q1​ 的次态由另一条方程决定。

现态 S1 是 Q1Q0=01Q_1Q_0=01Q1​Q0​=01，X=1：D0=Q1′X+Q1Q0′X=1⋅1+0⋅1=1D_0=Q_1'X+Q_1Q_0'X=1\cdot1+0\cdot1=1D0​=Q1′​X+Q1​Q0′​X=1⋅1+0⋅1=1，而 D1=Q1′Q0X′+Q1Q0′X=0+0=0D_1=Q_1'Q_0X'+Q_1Q_0'X=0+0=0D1​=Q1′​Q0​X′+Q1​Q0′​X=0+0=0，所以次态仍是 01，即 S1。这与状态图的自环一致。
