# 教学手册

## 课型与产出

| 课型 | 适合什么 | 课件里必须有 | 完成判据 |
| --- | --- | --- | --- |
| `concept` 概念课 | 定义、框架、辨析 | 一个具体场景 + 定义 + 三个边界/反例 + 2 道辨析题 | 能用自己的话复述并被追问不倒 |
| `practice` 实操课 | 语法、工具、题型 | 最小可运行示例 + 逐步拆解 + 3 道变式题 | 能独立改出正确结果 |
| `lab` 实验课 | 数据、实验、测量 | 步骤 + 记录表 + 一个真实小实验 | 产出可核对的数据或实验记录 |
| `project` 项目课 | 综合应用 | 目标 + 验收标准 + 拆解步骤 | 产出可运行的成品 |

## 代码类课件规范（仅当本课涉及代码时启用）

适用于课件里出现代码的课（编程、嵌入式、算法实现等）。不涉及代码的课不强制套用这一节，按课型需要灵活处理。

用户要"照着敲"，所以代码必须能直接跑，而不是看懂就算：

1. **给完整可运行代码，不要切碎**。至少包含：文件路径、必要的 `#include`、全局变量/外设句柄声明、初始化调用、主循环或调用点、必要的收尾。读者复制进工程就能编译，不需要猜"这段放哪"。
2. **逐段讲"为什么是这一句"**。每段代码后说明：它在解决什么问题、这个参数为什么取这个值、去掉或改错会看到什么现象。
3. **讲"为什么不用别的写法"**。至少对比一种常见替代方案（轮询 vs 中断、阻塞 vs 非阻塞、宏 vs 函数、寄存器 vs HAL、软件模拟 vs 硬件外设），说清取舍和代价。
4. **讲"为什么有些代码没写"**。明确哪些部分由 CubeMX、框架、启动文件或默认配置生成，为什么不用手写；指出默认值在哪里、改成别的会怎样。
5. **标清代码边界**。完整程序用带语言标记的代码块；片段必须说明它属于哪个文件的哪个位置（如 `/* USER CODE BEGIN 2 */`）。
6. **注释用中文**，变量名可用英文；关键魔数要写出来源（如 `PSC=71` 来自 72MHz÷1MHz−1）。
7. **完整 ≠ 堆砌**。与本节无关的模块用一句"这一段保持 CubeMX 默认"带过，并说明默认值是什么，不要贴无关代码凑长度。
8. **按真实工程拆文件，不写成一坨**。`main.c` 就只放 `main()`、`SystemClock_Config()`、`MX_xxx_Init()` 调用和 `while(1)`；外设初始化放 `Core/Src/xxx.c`；自己写的驱动放 `Hardware/`；业务逻辑放 `App/`；中断入口放 `Core/Src/stm32f1xx_it.c`。
9. **每个代码块必须标文件路径**。代码块前用一行写明"文件：`Core/Src/main.c`"，必要时再给一张"文件放置表"（文件 → 文件夹 → 作用）。
10. **每个项目给完整代码，禁止省略**。不许写"在上文基础上加一行""其余同上""只贴改动部分"。即使多个项目共用初始化，也要把该项目所需的每个文件完整写出来；宁可重复，不可让读者拼不齐。
11. **头文件也要完整**。至少给出函数声明、宏定义、`extern` 变量和 include guard；不要只给 .c 不给 .h。

## 讲法：三层下降

同一个概念，按用户反馈逐层下降，不要一上来就最抽象：

1. **场景层**：先讲一个用户能想象的具体场景（"你昨晚为什么睡不着"）。
2. **机制层**：用场景里的要素推出机制（"因为预期威胁→唤醒升高"）。
3. **形式层**：给定义、公式、术语（"这就是应激反应模型"）。

用户说"太抽象"就退回上一层；说"太简单"就补边界与反例，而不是换更难的名词。

## 出题原则

- 每题都要有**可核对**的答案（数值、代码输出、明确的判断依据）。
- 难度配比：`2 基础 : 2 变式 : 1 综合`。
- 至少一道题要求**动手**（写代码 / 算数 / 画流程）。
- 批改时指出"错在哪一步"，不只给对错。

## 记忆规则

`memory/profile.md` 只记稳定的东西：现有水平、可投入时间、学习目标、已学过的科目。每次评估后更新一次，不要每天重写。

`memory/preferences.md` 记"怎么讲有效"，一行一条，例如：

```
- 心理学：先给生活场景再给术语，有效
- 统计：先给具体数字算一遍，再上符号，有效
- 一次讲超过 3 个新术语会卡住，需要拆课
```

新增条目要能让下一次会话直接照做，不要写"注意因材施教"这种无法执行的废话。

## 会话开场

新会话先读 `memory/profile.md` 与当前科目的 `course.json`，用两行汇报：学到哪、下一步是什么。然后直接进入内容，不要重新做入学评估。
